# Be Bodywise

A web-based skincare and haircare experience.

## Features
- Interactive skincare and haircare quiz
- Personalized concern selection
- Skin and scalp type assessment
- Responsive user interface

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Project Structure
- app.js
- index.html
- style.css
- README.md

## Run Locally
Open index.html in your browser.
